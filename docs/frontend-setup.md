# Frontend Setup

## Requirements

* Node.js (optional)
* Static file server

---

# Running locally

Using serve:

```bash
npx serve .
```

Or simply open:

```txt
index.html
```

in a browser.

---

# Configuration

Edit:

```txt
config.js
```

Example:

```js
window.APP_CONFIG = {
  API_BASE: "https://api.example.com"
};
```

---

# Deployment

The frontend can be hosted on:

* GitHub Pages
* Netlify
* Vercel
* any static hosting provider

---

# Features

The frontend includes:

* live commit feed
* branch visualization
* contributor drilldowns
* release notes rendering
* analytics charts
* video previews
* admin mode UI
